🎯 Quiz Game — C++ Console Trivia Challenge

🧠 An interactive console-based Quiz Game built in C++, testing your knowledge across multiple categories with a fun, game-show style experience! 🎮

🕹️ How It Works
👤 Login — Enter your name and the current date to begin
📋 Main Menu — Choose Start Quiz, View High Scores, or Exit
📚 Select Subject & Difficulty — Pick a topic and mode (Easy/Medium/Hard)
🎲 Random Questions — Questions are randomly picked from the file based on your selection
⌨️ Enter Your Answer — Type your choice on the console
✅❌ Instant Feedback — Displays Correct! or Wrong! right away
🏆 Score & Leaderboard — Points tallied, streak bonuses applied, top scores saved
✨ Features
📚 5 Quiz Categories — Science, Sports, History, Computer, IQ/Logic
🎚️ 3 Difficulty Levels — Easy, Medium, Hard (with negative marking)
⏱️ Timed Questions — Answer before time runs out!
🛟 4 Lifelines — 50/50 🔀, Skip ⏭️, Replace 🔄, Extra Time ⏳
🔥 Streak Bonuses — Extra points for consecutive correct answers
🏆 High Score Leaderboard — Top 5 scores saved & displayed
👤 Player Login — Name & date tracked each session
🛠️ Tech Stack

C++ | File I/O | <conio.h> for real-time input & timer | Randomized question logic

🚀 Why This Project?

A hands-on way to practice C++ fundamentals — file handling, control flow, real-time input, and game logic — all wrapped into a genuinely fun, replayable quiz! 🕹️💡
